# Code Fade

**Gradual Comment Remover** は、ソースコード内のコメントを指定した割合で段階的に削除し、  
複数のバージョンを自動生成して保存できる Python スクリプトです。

---

## 特徴

- **標準ライブラリのみで動作**  
  このスクリプトは Python の標準ライブラリだけを使用するため、  
  追加のパッケージインストールは不要です。

- **対応 Python バージョン**  
  Python **3.6 以上** を推奨します。

- **`source/` に削除対象のソースコードを格納**  
  コメントを削除したいファイルを `source/` ディレクトリに入れてください。

- **簡単な実行方法**  
  以下のコマンドを打つだけで、コメントを段階的に削除したバージョンを出力します。

  ```bash
  python main.py
  ```

>段階ごとのディレクトリ自動生成
>output/ フォルダ内に v0, v25, v50, v100 といった除去段階のディレクトリが自動で作成され、
>それぞれの段階でコメントが段階的に除去されたソースが保存されます。

# ディレクトリ構造例
```ini
your_project/
├── source/            # 削除対象のソースコードを格納する
│   ├── example1.cpp
│   ├── example2.py
│   └── ...
├── output/            # バージョンごとの削除結果が自動生成される
│   ├── v0/
│   ├── v25/
│   ├── v50/
│   ├── v100/
├── main.py            # 実行スクリプト
├── README.md          # このドキュメント
```
# 使い方
**➀ source/ に解析・処理したいソースコードを入れます。**
**➁ ターミナルやコマンドプロンプトで次を実行：**
  ```bash
  python main.py
  ```
**➂ output/ フォルダに [0, 25, 50, 100] の割合でコメントを削除した
バージョンのソースコードが保存されます。**
>mainスクリプトの`VERSION`部分を変更することで任意のレベルでコメントを削除することができます。

# 動作環境
`Python 3.6 以上`

追加の外部パッケージ不要
（使用ライブラリ：os, re, random のみ）
